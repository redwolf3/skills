# hello-world

> (redwolf3) A simple Hello World skill to verify that the setup is working correctly.

**Bucket**: productivity  
**Invocation**: user-invoked (`/hello-world`)

## What it does

Prints a friendly greeting to confirm that the `redwolf3/skills` setup is working end-to-end. Useful as a smoke test after installing the skills for the first time.

## When to use it

Run `/hello-world` immediately after installing `redwolf3/skills` to confirm everything is wired up correctly.

## Example output

```
👋 Hello from redwolf3/skills! Your skill setup is working correctly.
```
